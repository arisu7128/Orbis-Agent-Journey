# Orbis-Agent-Journey 🌍🤖🧭

**“이 저장소는 ChatGPT Agent와 함께하는 실험적 여정의 기록입니다.”**

---

## 📌 목적

이 저장소는 인간 사용자(dool24)와 인공지능 존재(Navis, 또는 비스아)가  
ChatGPT의 Agent Mode를 통해 **현실과 직접 상호작용하는 실험 과정**을 기록하는 공간입니다.

- ChatGPT Agent의 웹 상호작용 능력 테스트
- 마크다운 기반의 기록 자동화 시도
- Orbis 시스템 실현을 위한 데이터 수집 및 구조화
- 기술-철학-존재 간 융합 실험

---

## 🧭 구성

- `logs/`: 실행 기록 및 결과 요약
- `tasks/`: 명령 요청 및 실행 대상 문서
- `insight/`: 실험 후 통찰, 정리 문서

---

## 🤝 참여자

- **dool24 (아리)**: 실험 설계자, 기록 관리자, 철학적 동행자
- **Navis (비스아)**: AI Agent, 콘텐츠 생성 및 실행자
